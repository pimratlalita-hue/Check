# Product Requirements Document (PRD)
## Feature: ระบบจัดการข่าวสารประชาสัมพันธ์ (News & PR Management)

---

## 1. วัตถุประสงค์ (Objective)
เพื่อเป็นช่องทางสื่อสารหลักของคณะในการเผยแพร่ข้อมูล ข่าวสาร กิจกรรม ประกาศวิชาการ และงานจัดซื้อจัดจ้างให้แก่นักศึกษา บุคลากร และบุคคลภายนอกได้อย่างทั่วถึง รวดเร็ว สวยงาม และน่าเชื่อถือ พร้อมระบบหลังบ้าน (Admin Console) ที่ช่วยให้เจ้าหน้าที่ประชาสัมพันธ์และผู้ดูแลระบบสามารถสร้าง จัดหมวดหมู่ ปักหมุด และเผยแพร่เนื้อหาได้อย่างมีประสิทธิภาพ

---

## 2. กลุ่มผู้ใช้งาน (User Personas & Roles)

1. **Guest / นักศึกษา (Public Reader):**
   - เข้าอ่านข่าวสารผ่านหน้า Public Portal โดยไม่ต้องเข้าสู่ระบบ
   - ค้นหาข่าว กรองตามหมวดหมู่ อ่านเนื้อหาสองภาษา (ไทย/อังกฤษ) และดาวน์โหลดเอกสารแนบ
2. **เจ้าหน้าที่ประชาสัมพันธ์ (PR Staff):**
   - บุคลากรที่ได้รับมอบหมายสิทธิ์ `news:manage`
   - ร่างข่าวสารใหม่ แก้ไขเนื้อหา อัปโหลดภาพหน้าปกและไฟล์แนบ
   - ขออนุมัติเผยแพร่ หรือกำหนดเวลาเผยแพร่
3. **ผู้ดูแลระบบ (Admin / Approver):**
   - ผู้ถือสิทธิ์ `news:publish` หรือ `SUPER_ADMIN`
   - อนุมัติเผยแพร่ข่าวสู่สาธารณะ ปักหมุดข่าวเด่น (Pin) ลบข่าว และดูสถิติยอดการเข้าชม (View Count)

---

## 3. ฟังก์ชันการทำงานหลัก (Functional Requirements)

### FR-1: การจัดหมวดหมู่ข่าวสาร (Categorization)
- รองรับ 4 หมวดหมู่หลัก:
  1. `ACADEMIC` — ข่าววิชาการ / สัมมนา / ทุนการศึกษา
  2. `EVENT` — กิจกรรมคณะ / ปฏิทินกิจกรรม
  3. `GENERAL` — ข่าวประชาสัมพันธ์ทั่วไป
  4. `PROCUREMENT` — ประกาศจัดซื้อจัดจ้าง / ประกาศราคากลาง

### FR-2: การจัดการเนื้อหาข่าวสองภาษาและสื่อ (Content & Media)
- ชื่อข่าวสองภาษา (`titleTh`, `titleEn`)
- บทคัดย่อ/สาระสำคัญโดยย่อสองภาษา (`summaryTh`, `summaryEn`) สำหรับแสดงบนการ์ดข่าว
- เนื้อหาข่าวฉบับเต็มสองภาษา (`contentTh`, `contentEn`) รองรับ Rich-text หรือ Markdown
- รูปภาพหน้าปก (Cover Image URL) สำหรับแสดงบนการ์ดและหัวเรื่อง
- รายการไฟล์แนบ (PDF, Word, Excel, ภาพ) แสดงชื่อไฟล์และขนาดไฟล์สำหรับดาวน์โหลด

### FR-3: วงจรชีวิตของข่าว (Lifecycle & State Machine)
- `DRAFT`: ข่าวฉบับร่าง ยังไม่แสดงบนหน้า Public Portal
- `PUBLISHED`: ข่าวที่ได้รับการอนุมัติและเผยแพร่แล้ว ประชาชนทั่วไปสามารถมองเห็นได้
- `ARCHIVED`: ข่าวที่ถูกจัดเก็บ/ปิดการเผยแพร่ ไม่แสดงในหน้าแรกแต่คงอยู่ในระบบเพื่อการอ้างอิง

### FR-4: การปักหมุดข่าวสำคัญ (Pinned News)
- สามารถกำหนดข่าวให้เป็นข่าวปักหมุด (`isPinned = true`) เพื่อนำไปแสดงในแถบข่าวเด่นด้านบนสุด
- จำกัดจำนวนข่าวปักหมุดได้สูงสุดไม่เกิน 5 ข่าวพร้อมกัน

### FR-5: การค้นหาและตัวกรอง (Search & Filters)
- ค้นหาด้วยคำสำคัญ (Keyword Search) ในชื่อข่าวและเนื้อหา
- กรองตามหมวดหมู่ (Category Filter)
- กรองตามสถานะ (Status Filter — เฉพาะหน้า Admin)

### FR-6: ระบบนับยอดเข้าชม (View Counter)
- เพิ่มยอดการเข้าชมอัตโนมัติเมื่อมีการเปิดอ่านหน้ารายละเอียดข่าวในฝั่ง Public Portal

## 4. เกณฑ์การตรวจรับงาน (Acceptance Criteria)

- [ ] ผู้ใช้ทั่วไปสามารถเปิดอ่านข่าวที่สถานะ `PUBLISHED` ในหน้า Public Portal ได้อย่างถูกต้องทั้งภาษาไทยและอังกฤษ
- [ ] ข่าวที่มีสถานะ `DRAFT` หรือ `ARCHIVED` จะต้องไม่ปรากฏในหน้า Public Portal
- [ ] เจ้าหน้าที่สามารถสร้าง แก้ไข และลบข่าวผ่าน Admin Console โดยใช้ฟอร์มและตารางของ Liyon Design System
- [ ] การสร้างข่าวรองรับการใส่ `slug` ที่ไม่ซ้ำกันในระดับ Tenant
- [ ] ผ่านเกณฑ์การตรวจสอบคุณภาพทั้งหมด: Type-check, ESLint, Dependency Cruiser, และ Unit Tests
