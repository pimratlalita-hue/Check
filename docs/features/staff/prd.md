# Product Requirements Document (PRD)
## Feature: ทำเนียบบุคลากรและอาจารย์ (Faculty & Staff Directory)

---

## 1. วัตถุประสงค์ (Objective)
เพื่อสร้างศูนย์กลางข้อมูลบุคลากรและคณาจารย์ประจำคณะที่เป็นระเบียบ น่าเชื่อถือ สวยงาม และเข้าถึงได้ง่าย ทั้งสำหรับบุคคลภายนอก นักศึกษา นักวิจัย และบุคลากรภายในคณะ:
- **Public Portal:** ช่วยให้นักศึกษาและบุคคลภายนอกสามารถค้นหาอาจารย์ที่ปรึกษา, ตรวจสอบรายชื่อคณะผู้บริหาร, ค้นหาผู้เชี่ยวชาญตามหัวข้องานวิจัย (Research Expertise), ดูช่องทางติดต่อและเวลาเข้าพบ (Office Hours), และเชื่อมต่อไปยังผลงานวิชาการ (Google Scholar, Scopus, ORCID)
- **Admin Console:** มอบระบบจัดการข้อมูลหลังบ้านให้เจ้าหน้าที่ฝ่ายบริหารงานบุคคล สามารถเพิ่ม ปรับปรุงข้อมูล จัดสังกัดภาควิชา กำหนดตำแหน่งบริหาร และควบคุมการแสดงผลได้อย่างสะดวกรวดเร็วตามมาตรฐาน Liyon Design System

---

## 2. กลุ่มผู้ใช้งาน (User Personas & Roles)

1. **Guest / นักศึกษา (Public Visitors & Students):**
   - ค้นหาอาจารย์ตามชื่อ ภาควิชา ตำแหน่ง หรือคำสำคัญด้านความเชี่ยวชาญ (เช่น AI, Big Data, Network Security)
   - ดูข้อมูลติดต่อ อีเมล หมายเลขโทรศัพท์ และห้องทำงานเพื่อติดต่อราชการหรือนัดหมาย
   - ตรวจสอบประวัติการศึกษาและลิงก์ผลงานทางวิชาการเพื่อประกอบการเลือกอาจารย์ที่ปรึกษาวิทยานิพนธ์
2. **เจ้าหน้าที่ฝ่ายบุคคล / เจ้าหน้าที่คณะ (HR & Faculty Staff):**
   - ผู้ถือสิทธิ์ `staff:manage`
   - เพิ่มข้อมูลบุคลากรใหม่ แก้ไขข้อมูล อัปเดตรูปถ่าย จัดกลุ่มภาควิชา และระบุประวัติการศึกษา/ความเชี่ยวชาญ
3. **ผู้บริหารและผู้ดูแลระบบ (Admin / Super Admin):**
   - ผู้ถือสิทธิ์ `staff:read` และ `staff:manage`
   - ตรวจสอบความถูกต้องของข้อมูลบุคลากรทั้งหมด กำหนดลำดับคณะผู้บริหาร (Executive Board) และส่งออกข้อมูล

## 3. ฟังก์ชันการทำงานหลัก (Functional Requirements)

### FR-1: การจัดกลุ่มภาควิชาและสายงาน (Departments & Staff Types)
- รองรับการแบ่งภาควิชา/ฝ่ายงาน (`Department`): รหัส, ชื่อไทย, ชื่ออังกฤษ, คำอธิบาย, ลำดับการแสดง
- รองรับการจำแนกประเภทบุคลากร (`StaffType`):
  1. `ACADEMIC` — สายวิชาการ / อาจารย์ประจำ
  2. `SUPPORT` — สายสนับสนุนวิชาการ / เจ้าหน้าที่สายสนับสนุน
  3. `EXECUTIVE` — คณะผู้บริหาร
- รองรับตำแหน่งทางวิชาการตามมาตรฐานอุดมศึกษา (`AcademicRank`):
  1. `PROFESSOR` (ศาสตราจารย์ / ศ.)
  2. `ASSOCIATE_PROFESSOR` (รองศาสตราจารย์ / รศ.)
  3. `ASSISTANT_PROFESSOR` (ผู้ช่วยศาสตราจารย์ / ผศ.)
  4. `LECTURER` (อาจารย์ / อ.)
  5. `NONE` (ไม่มีตำแหน่งทางวิชาการ)

### FR-2: ข้อมูลส่วนตัวและตำแหน่งงาน (Personal & Position Profile)
- คำนำหน้านามและชื่อ-สกุลสองภาษา (`prefixTh`, `firstNameTh`, `lastNameTh`, `prefixEn`, `firstNameEn`, `lastNameEn`)
- ตำแหน่งบริหารและตำแหน่งงานสองภาษา (`positionTh`, `positionEn`) เช่น "คณบดี", "หัวหน้าภาควิชา", "นักวิชาการคอมพิวเตอร์"
- ธงสถานะผู้บริหาร (`isExecutive = true`), ระบุตำแหน่งบริหาร (`executiveRole`), และลำดับการแสดงผล (`executiveOrder`) สำหรับจัดแสดงในแถบทำเนียบผู้บริหาร

### FR-3: ช่องทางติดต่อและห้องทำงาน (Contact & Office Info)
- อีเมลติดต่อทางการ (`email`)
- หมายเลขโทรศัพท์ภายใน/ติดต่อ (`phone`)
- ที่ตั้งห้องทำงาน (`officeRoom`) เช่น "อาคาร 3 ชั้น 4 ห้อง 3402"
- เวลาให้คำปรึกษาแก่นักศึกษา (`officeHours`) เช่น "วันจันทร์และพุธ 13:00 - 15:00 น."
- ลิงก์รูปถ่ายประจำตัว (`avatarUrl`)

### FR-4: ประวัติการศึกษา ผลงานวิจัย และความเชี่ยวชาญ (Academic Portfolio)
- ประวัติการศึกษา (`education` — JSON Array) เช่น วท.บ. วิทยาการคอมพิวเตอร์, วท.ม., Ph.D.
- ความเชี่ยวชาญ / คีย์เวิร์ดงานวิจัย (`expertise` — JSON Array of strings) เช่น `["Artificial Intelligence", "Computer Vision", "Deep Learning"]`
- หัวข้องานวิจัยที่สนใจ (`researchInterests` — Text)
- ลิงก์เชื่อมโยงฐานข้อมูลวิชาการระดับสากล:
  - Google Scholar Profile URL (`googleScholarUrl`)
  - Scopus Author ID / Profile URL (`scopusUrl`)
  - ORCID ID (`orcidId`)
  - เว็บไซต์ส่วนตัว / ห้องปฏิบัติการ (`websiteUrl`)
- ประวัติและผลงานโดยย่อสองภาษา (`bioTh`, `bioEn`)

### FR-5: ระบบค้นหาและตัวกรอง (Search & Filter Directory)
- ค้นหาแบบ Real-time ด้วยชื่ออาจารย์, สังกัด, ตำแหน่ง, หรือความเชี่ยวชาญ
- กรองตามแท็บภาควิชา (Department Tabs)
- สลับแท็บสายงาน: ทั้งหมด / สายวิชาการ / สายสนับสนุน / ผู้บริหาร

### FR-6: การจัดการข้อมูลหลังบ้าน (Admin Management)
- เพิ่ม แก้ไข และลบข้อมูลบุคลากรและภาควิชา
- ปิด/เปิดการแสดงผลในหน้าเว็บสาธารณะทันที (`isActive` toggle)
- จัดเรียงลำดับการแสดงผล (`displayOrder`)

## 4. เกณฑ์การตรวจรับงาน (Acceptance Criteria)

- [ ] ผู้ใช้ภายนอกสามารถเปิดดูหน้า `/portal/staff` แสดงรายชื่อบุคลากรที่ `isActive = true` แบ่งตามหมวดหมู่ได้ถูกต้อง
- [ ] มีแถบแสดงคณะผู้บริหาร (Executive Board) พร้อมจัดลำดับอย่างถูกต้อง
- [ ] ผู้ใช้สามารถคลิกดูหน้ารายละเอียด `/portal/staff/[id]` เพื่อดูประวัติการศึกษา ความเชี่ยวชาญ ลิงก์ Google Scholar/Scopus ได้อย่างสวยงาม
- [ ] ระบบค้นหาทำงานได้ลื่นไหล รองรับการพิมพ์ค้นหาทั้งภาษาไทยและอังกฤษ
- [ ] เจ้าหน้าที่สามารถจัดการข้อมูลบุคลากรผ่านหน้า `/staff` ใน Admin Console โดยใช้แบบฟอร์ม Liyon Design System
- [ ] ทุกฟังก์ชันผ่านเกณฑ์การทดสอบคุณภาพ: `type-check`, `lint`, `deps:check`, และ `test` 100%
