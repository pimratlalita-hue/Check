# Product Requirements Document (PRD)
## Feature: ระบบจัดการหลักสูตรการศึกษา (Academic Programs & Curriculum Management)

---

## 1. วัตถุประสงค์ (Objective)
เพื่อเป็นศูนย์กลางรวบรวมและเผยแพร่ข้อมูลหลักสูตรการศึกษาของคณะทุกระดับ (ปริญญาตรี, ปริญญาโท, ปริญญาเอก, และหลักสูตรระยะสั้น/ประกาศนียบัตร) ให้แก่นักเรียน นักศึกษา ผู้ปกครอง และบุคคลทั่วไป ได้ศึกษาโครงสร้างหลักสูตร แผนการเรียน ผลลัพธ์การเรียนรู้ (PLOs) ค่าธรรมเนียมการศึกษา โอกาสในการประกอบอาชีพ และดาวน์โหลดคู่มือหลักสูตร (มคอ.2) พร้อมระบบจัดการหลังบ้าน (Admin Console) สำหรับฝ่ายวิชาการในการปรับปรุงข้อมูลหลักสูตรได้อย่างเป็นระบบ

---

## 2. กลุ่มผู้ใช้งาน (User Personas & Roles)

1. **ผู้สนใจศึกษาต่อ / นักศึกษา (Prospective Students & Current Students):**
   - เข้าดูข้อมูลหลักสูตรผ่านหน้า Public Portal โดยไม่ต้องเข้าสู่ระบบ
   - กรองตามระดับการศึกษา (ตรี, โท, เอก) และประเภทหลักสูตร (ไทย, นานาชาติ)
   - ศึกษารายวิชาสำคัญ, ผลลัพธ์การเรียนรู้ (PLOs), ค่าธรรมเนียม, โอกาสทางอาชีพ และดาวน์โหลดเล่ม มคอ.2
2. **เจ้าหน้าที่ฝ่ายวิชาการและพัฒนาหลักสูตร (Academic Affairs Staff):**
   - บุคลากรที่ได้รับมอบหมายสิทธิ์ `curriculum:manage`
   - เพิ่มหลักสูตรใหม่ ปรับปรุงโครงสร้างหน่วยกิต เพิ่มรายวิชาสำคัญ อัปโหลดเล่มหลักสูตร PDF
3. **ผู้บริหารและประธานหลักสูตร (Admin & Program Chairs):**
   - ผู้ถือสิทธิ์ `curriculum:read` และ `curriculum:manage`
   - ตรวจสอบความถูกต้องของข้อมูลหลักสูตร เปิด/ปิดการแสดงผลสู่สาธารณะ

## 3. ฟังก์ชันการทำงานหลัก (Functional Requirements)

### FR-1: การจำแนกระดับและประเภทหลักสูตร (Classification)
- ระดับการศึกษา (`DegreeLevel`):
  1. `BACHELOR` — ระดับปริญญาตรี
  2. `MASTER` — ระดับปริญญาโท
  3. `DOCTORAL` — ระดับปริญญาเอก
  4. `CERTIFICATE` — ประกาศนียบัตร / หลักสูตรระยะสั้น (Non-degree)
- ประเภทหลักสูตร (`ProgramType`):
  1. `THAI` — หลักสูตรภาษาไทย
  2. `INTERNATIONAL` — หลักสูตรนานาชาติ (English / International Program)
  3. `BILINGUAL` — หลักสูตรสองภาษา

### FR-2: ข้อมูลหลักสูตรสองภาษาและโครงสร้าง (Program Info & Structure)
- รหัสหลักสูตร (`code`) เช่น `B.Eng.-CPE`, `M.Sc.-AI`, `Ph.D.-CS`
- Slug ไม่ซ้ำกันในระดับ Tenant เช่น `bachelor-computer-engineering`
- ชื่อหลักสูตรภาษาไทยและอังกฤษ (`titleTh`, `titleEn`)
- ชื่อย่อปริญญาภาษาไทยและอังกฤษ (`degreeNameTh`, `degreeNameEn`) เช่น "วศ.บ. (วิศวกรรมคอมพิวเตอร์) / B.Eng. (Computer Engineering)"
- จำนวนหน่วยกิตรวม (`creditsTotal`) เช่น 132 หน่วยกิต
- ระยะเวลาการศึกษาตามแผน (`durationYears`) เช่น 4 ปี, 2 ปี
- ค่าธรรมเนียมการศึกษา (`tuitionFee`) เช่น "28,000 บาท/ภาคการศึกษา"
- สังกัดภาควิชา (`departmentId`)

### FR-3: ผลลัพธ์การเรียนรู้และเส้นทางอาชีพ (PLOs & Career Paths)
- สาระสำคัญ/วัตถุประสงค์ของหลักสูตร (`descriptionTh`, `descriptionEn`)
- ผลลัพธ์การเรียนรู้ที่คาดหวังของหลักสูตร (`learningOutcomes` — JSON Array of strings)
- อาชีพและเส้นทางสายงานที่รองรับ (`careerPaths` — JSON Array of strings)
- ลิงก์ดาวน์โหลดเล่ม มคอ.2 PDF (`curriculumPdfUrl`)
- รูปภาพหน้าปกหลักสูตร (`coverImageUrl`)

### FR-4: หมวดวิชาและรายวิชาสำคัญ (Curriculum Structure & Key Courses)
- รายการรายวิชาสำคัญในหลักสูตร (`ProgramCourse`):
  - รหัสวิชา, ชื่อวิชา (TH/EN), จำนวนหน่วยกิต
  - หมวดวิชา (`category`): หมวดศึกษาทั่วไป, หมวดวิชาเฉพาะ, หมวดเลือกเสรี, วิทยานิพนธ์/สารนิพนธ์
  - ภาคการศึกษาและชั้นปีตามแผน (`year`, `semester`)

### FR-5: ระบบค้นหาและตัวกรอง (Search & Filter)
- กรองตามระดับการศึกษา (Tabs: ปริญญาตรี / โท / เอก)
- กรองตามภาควิชา/สาขาวิชา และประเภทหลักสูตร
- ค้นหาด้วยคำสำคัญในชื่อหลักสูตรและชื่อย่อปริญญา

## 4. เกณฑ์การตรวจรับงาน (Acceptance Criteria)

- [ ] ผู้ใช้ทั่วไปสามารถเปิดดูหน้ารายการหลักสูตร `/portal/curriculum` แบ่งตามระดับการศึกษาได้ถูกต้อง
- [ ] ผู้ใช้สามารถคลิกดูรายละเอียดหลักสูตร `/portal/curriculum/[slug]` แสดง PLOs, โครงสร้างรายวิชา, โอกาสทางอาชีพ, และลิงก์ดาวน์โหลด มคอ.2 PDF ได้อย่างครบถ้วน
- [ ] เจ้าหน้าที่สามารถสร้าง แก้ไข และลบข้อมูลหลักสูตรผ่านหน้า `/curriculum` ใน Admin Console โดยใช้ฟอร์มของ Liyon Design System
- [ ] ผ่านเกณฑ์การตรวจสอบคุณภาพทั้งหมด: Type-check, ESLint, Dependency Cruiser, Unit Tests, และ Integration Tests
