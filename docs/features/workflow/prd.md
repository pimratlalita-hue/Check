# Product Requirements Document (PRD)
## Feature: ระบบคำร้องและกระบวนการขออนุมัติเอกสารออนไลน์ (Document & Approval Workflow)

---

## 1. บทนำและภาพรวม (Introduction & Overview)

ในระบบการศึกษาระดับอุดมศึกษาและบัณฑิตวิทยาลัย การยื่นและติดตามคำร้องทางวิชาการ (Academic Petitions) เช่น การขออนุมัติหัวข้อวิทยานิพนธ์ การขอสอบจบปากเปล่า การขอลาพักการศึกษา หรือการขอขยายเวลาการศึกษา มักประสบปัญหาความล่าช้า การสูญหายของเอกสารกระดาษ และความยากลำบากในการติดตามว่าเอกสารกำลังค้างอยู่ที่ขั้นตอนหรือผู้มีอำนาจลงนามท่านใด

ฟีเจอร์ **Document & Approval Workflow (`workflow`)** ถูกพัฒนาขึ้นเป็นแกนกลางลำดับที่ 4 ของแพลตฟอร์มคณะวิชา (`Project 1`) เพื่อปฏิรูประบบคำร้องให้เป็นดิจิทัลไร้กระดาษ (Paperless e-Petition) 100% มีระบบอนุมัติตามลำดับชั้น 4 ระดับ (Hierarchical 4-Tier Approval State Machine) พร้อมระบบออกหมายเลขติดตามคำร้อง (Tracking Number) ที่สามารถตรวจสอบสถานะได้แบบเรียลไทม์

---

## 2. กลุ่มเป้าหมายผู้ใช้งาน (Target Personas)

1. **นิสิต / นักศึกษา (Students):**
   - ยื่นคำร้องวิชาการออนไลน์ได้อย่างสะดวกสบายทุกที่ทุกเวลา
   - แนบไฟล์ข้อเสนอเค้าโครงวิทยานิพนธ์ หรือเอกสารประกอบ
   - ค้นหาและติดตามสถานะคำร้องด้วยหมายเลขคำร้อง (Tracking No.) หรือรหัสนิสิต ดู Stepper แสดงสถานะปัจจุบันแบบโปร่งใส

2. **อาจารย์ที่ปรึกษา (Thesis / Academic Advisors):**
   - ตรวจสอบคำร้องของนิสิตในความดูแลผ่าน Admin Console
   - พิจารณาอนุมัติให้ความเห็นชอบ, ส่งกลับให้นิสิตปรับปรุงแก้ไขพร้อมระบุข้อเสนอแนะ, หรือปฏิเสธคำร้อง

3. **ประธานหลักสูตร / หัวหน้าภาควิชา (Program Chairs / Department Heads):**
   - พิจารณากลั่นกรองคำร้องที่ผ่านความเห็นชอบจากอาจารย์ที่ปรึกษาแล้ว
   - ตรวจสอบความสอดคล้องกับเกณฑ์มาตรฐานหลักสูตรก่อนส่งต่อสำนักงานคณะ

4. **สำนักงานคณบดีและบัณฑิตวิทยาลัย (Dean's Office / Graduate School):**
   - พิจารณาอนุมัติขั้นสุดท้าย (Final Approval)
   - ออกคำสั่ง ออกเลขที่หนังสือ หรือออกเอกสารรับรองอย่างเป็นทางการ
   - ดูภาพรวมสถิติคำร้อง (Dashboard KPIs) ของทั้งคณะ

---

## 3. ประเภทคำร้องที่รองรับ (Supported Academic Petition Types)

1. **`THESIS_TOPIC_APPROVAL` (คำร้องขออนุมัติหัวข้อและเค้าโครงวิทยานิพนธ์):**
   - บันทึกชื่อวิทยานิพนธ์ภาษาไทยและภาษาอังกฤษ
   - แนบไฟล์เค้าโครงวิทยานิพนธ์ (Proposal PDF)
2. **`DEFENSE_EXAM_REQUEST` (คำร้องขอสอบปากเปล่า/สอบจบวิทยานิพนธ์):**
   - ตรวจสอบเงื่อนไขการสอบจบและแนบเล่มวิทยานิพนธ์ฉบับสมบูรณ์
3. **`LEAVE_OF_ABSENCE` (คำร้องขอลาพักการศึกษา / รักษาสถานภาพ):**
   - ระบุภาคการศึกษาและปีการศึกษาที่ขอลาพัก พร้อมเหตุผลความจำเป็น
4. **`EXTENSION_OF_STUDY` (คำร้องขอขยายเวลาการศึกษา):**
   - ระบุระยะเวลาที่ขอขยาย และรายงานความก้าวหน้า
5. **`GENERAL_PETITION` (คำร้องทั่วไป / ขอหนังสือรับรอง):**
   - คำร้องทางวิชาการอื่นๆ หรือการขอเอกสารรับรองพิเศษ

## 4. กระบวนการอนุมัติตามลำดับขั้น (Hierarchical Approval State Machine)

```text
[นิสิตยื่นคำร้อง] (SUBMITTED, Step 1)
         │
         ▼
[อาจารย์ที่ปรึกษาพิจารณา] ──(ส่งกลับแก้ไข)──> [RETURNED] ──(นิสิตแก้ไขยื่นใหม่)──┐
         │ (อนุมัติ)                                                              │
         ▼                                                                        │
[ประธานหลักสูตรพิจารณา] (ADVISOR_APPROVED, Step 2)                                │
         │ (อนุมัติ)                                                              │
         ▼                                                                        │
[บัณฑิตวิทยาลัย/คณบดี] (CHAIR_APPROVED, Step 3)                                  │
         │ (อนุมัติขั้นสุดท้าย)                                                     │
         ▼                                                                        │
[เสร็จสมบูรณ์] (COMPLETED, Step 4)                                               │
         ▲                                                                        │
         └────────────────────────────────────────────────────────────────────────┘

*หมายเหตุ: ในทุกขั้นตอนการพิจารณา ผู้มีสิทธิ์สามารถปฏิเสธ (REJECTED) ได้เสมอ
```

## 5. ฟังก์ชันการทำงานหลัก (Core Functional Requirements)

### 5.1 Public Portal: ยื่นคำร้องและติดตามสถานะ (`/portal/petitions`)
- ฟอร์มยื่นคำร้องออนไลน์:
  - ข้อมูลผู้ยื่น: รหัสนิสิต, ชื่อ-นามสกุล, อีเมล, เบอร์โทรศัพท์
  - ข้อมูลวิชาการ: เลือกระดับการศึกษา, เลือกหลักสูตร (`Program`), เลือกอาจารย์ที่ปรึกษา (`StaffProfile`)
  - รายละเอียดคำร้อง: ประเภทคำร้อง, หัวข้อ, คำอธิบายเหตุผล, ชื่อวิทยานิพนธ์ (กรณีวิทยานิพนธ์), URL ไฟล์แนบ
- ระบบออกรหัสคำร้องอัตโนมัติ (Format: `REQ-YYYY-XXXX` เช่น `REQ-2026-0001`)
- หน้าติดตามสถานะคำร้อง (Track Petition Status):
  - ค้นหาด้วยหมายเลข Tracking No. หรือรหัสนิสิต
  - แสดง Visual Stepper แสดงขั้นตอน 4 ระดับ พร้อมระบุว่าคำร้องอยู่ที่ใคร
  - แสดงประวัติการดำเนินการ (Audit Timeline) และความคิดเห็นของอาจารย์

### 5.2 Admin Console: จัดการและพิจารณาคำร้อง (`/workflow`)
- การ์ดสรุปสถิติ (KPI Stats):
  - คำร้องทั้งหมด (Total Requests)
  - รอการพิจารณา (Pending Approval)
  - อนุมัติเสร็จสมบูรณ์ (Completed)
  - ส่งกลับแก้ไข/ปฏิเสธ (Returned / Rejected)
- Liyon `DataTable`:
  - คอลัมน์: Tracking No., ผู้ยื่น (รหัส & ชื่อ), ประเภทคำร้อง, อาจารย์ที่ปรึกษา, วันที่ยื่น, สถานะ (StatusPill), ขั้นตอนปัจจุบัน
  - ตัวกรอง: ประเภทคำร้อง, สถานะคำร้อง, ช่องค้นหา
- โมดอลพิจารณาคำร้อง (`PetitionReviewDialog`):
  - ดูรายละเอียดคำร้องครบถ้วน พร้อมลิงก์เปิดดูเอกสารแนบ
  - ดูไทม์ไลน์ประวัติการดำเนินการ
  - ส่วนการตัดสินใจ (Action Form):
    - ปุ่ม **อนุมัติ (Approve)** $\rightarrow$ เลื่อนไปยังขั้นตอนถัดไป
    - ปุ่ม **ส่งกลับแก้ไข (Return for Revision)** $\rightarrow$ ส่งกลับให้นิสิตแก้ไข
    - ปุ่ม **ปฏิเสธ (Reject)** $\rightarrow$ สิ้นสุดคำร้อง
    - ช่องกรอกความคิดเห็น / คำแนะนำ (Comments)

## 6. ข้อกำหนดด้านความปลอดภัยและคุณภาพ (Non-Functional Requirements)

1. **Modular Monolith & Dependency Cruiser:**
   - โค้ดทั้งหมดต้องอยู่ภายใต้ `src/features/workflow/`
   - การเรียกใช้จากภายนอกทำผ่าน `index.ts`, `server.ts`, `actions.ts` เท่านั้น
2. **Multi-Tenancy & RBAC:**
   - ทุกเรคอร์ดมี `tenantId`
   - ตรวจสอบสิทธิ์ด้วย `requirePermission(session, "workflow:read")` และ `requirePermission(session, "workflow:manage")`
3. **i18n Support:**
   - รองรับสองภาษา (ภาษาไทยและภาษาอังกฤษ) 100% ไม่มี hardcoded string ใน UI
4. **Quality Gates:**
   - Unit tests ครอบคลุม State machine logic
   - Integration tests บนฐานข้อมูลจริง
   - ผ่าน `npm run check` (TypeScript, ESLint, Boundaries, Unit, Integration) 100%
